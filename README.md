# 月夜の短編集

ニュース、三枚の大アルカナ、短編小説を組み合わせた独立ブログです。静的HTMLのみで動作し、Cloudflare Pagesの無料枠で配信できます。

## 公開フロー（承認型）

1. 原稿と制作記録はNotionに保存する。
2. 公開承認を得るまではGitHubへ追加しない。
3. 承認済み原稿だけを `stories/YYYY-MM-DD/` に追加する。
4. 日付別・題名別一覧を更新し、GitHubの既定ブランチへ反映する。
5. Cloudflare Pagesが既定ブランチを自動配信する。

Notionとの自動同期は行いません。これにより、下書きや未承認原稿が誤って公開されることを防ぎます。

## 技術構成

- ビルド不要の静的HTML/CSS
- 外部JavaScript、データベース、サーバー処理なし
- 既存タロットアプリの大アルカナ22枚をSVG資産として再利用
- 既存タロットアプリのリポジトリや公開環境には変更を加えない
